# Privacy Policy — Fission

**Last updated:** November 2026

Fission is a local-only Chrome extension. Your privacy is guaranteed by architecture:

- **No data collection:** Fission does not collect, track, log, or transmit any personal data, browsing history, usage analytics, or crash reports.
- **100% local storage:** All topics, tasks, progress states, countdown timers, and UI preferences are stored exclusively on your device using Chrome's `chrome.storage.local` API.
- **No network requests:** Fission makes zero external network calls, uses no third-party servers, and loads no remotely hosted code. All assets (including PDF export and CJK font support) are bundled inside the extension package.
- **No accounts or third-party sharing:** Fission requires no sign-in and never sells or shares data with third parties.
- **Data deletion:** Uninstalling Fission or clearing extension data in Chrome permanently deletes all stored checklists from your device.

If you have questions, please open an issue in the project's GitHub repository.
